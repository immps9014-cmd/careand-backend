# Care& 가격 레이어 도입 — 경영 보고 요약

**일자** 2026-06-27 · **한 줄 요약** 시장 1위 케어네이션의 최대 경쟁우위인 **"적정 간병비 + 역경매"**를 Care&에 이식하여 가격 경쟁력·매칭 전환의 구조적 격차를 해소함.

---

### 1. 배경 — 경쟁 격차
- **케어네이션**(시장 1위, 누적투자 305억, 회원 50만+)의 핵심 해자는 ① **적정 간병비 자동 산출** ② **역경매 입찰**(돌봄전문가가 가격 제시 → 보호자 선택).
- **Care&는 가격 기능이 부재**했음 — 카테고리별 정액 단가뿐이라, 가격 투명성·협상·가성비 비교가 불가능했음. (벤치마킹 갭 **1순위**)

### 2. 추진 내용 — 가격 레이어 3단계 (전부 완료·배포)
| 단계 | 기능 | 고객 가치 |
|---|---|---|
| **① 적정 간병비 산출** | 지역·시간대(야간/공휴일)·난이도·긴급도 보정 + 실거래가 학습으로 **권장 시급대 제시** | 보호자: "얼마가 적정한지" 즉시 확인 / 깜깜이 가격 해소 |
| **② 역경매 입찰** | 돌봄전문가가 시급 제시 → 보호자가 비교 후 선택 = **즉시 확정** (자동입찰 지원) | 가격 경쟁 유도, 보호자 선택권 확대, 전문가 수입 자율화 |
| **③ 가성비 추천** | AI 매칭 점수에 **가격 대비 가치** 반영해 추천순 보정 | "잘 맞으면서 합리적인" 후보를 상단 노출 |

- **안전장치**: 최저임금 미만 입찰 차단, 권장가 이탈 시 경고, 보호자 희망 상한 설정.
- **양면 UI 완비**: 보호자(권장가·예산·입찰 비교)·돌봄전문가(입찰·자동입찰 설정) 화면 모두 배포.

### 3. 기대 효과
- **전환율** — 가격 불확실성 제거로 요청→매칭 전환 개선 기대.
- **공급 확대** — 전문가가 직접 단가를 제시(자율 수입)해 참여 유인 강화.
- **차별화** — 케어네이션 대비 **매칭 근거·가격 산출 투명성**에서 우위(동성 매칭 정교함 포함).

### 4. 현황 & 다음 단계
- **현황**: 3단계 + 양면 UI **전부 개발·검증·라이브 배포 완료**. 설정 토글로 단계별 on/off 가능.
- **잔여 과제(우선순위순)**:
  1. **결제·정산 실연동**(PG 실결제, 가상계좌, 배상책임보험) — 거래 신뢰 인프라
  2. **지역별 단가 데이터** 확충(현재 전국 기본값)
  3. 네이티브 앱, ML 매칭 고도화

> **요약**: 경쟁사 대비 가장 큰 제품 격차였던 "가격"을 해소했고, 다음 분기 과제는 **결제·정산 실연동**으로 거래 완결성을 확보하는 것입니다.
